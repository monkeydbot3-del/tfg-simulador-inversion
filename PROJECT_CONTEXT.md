# PROJECT_CONTEXT.md

## Nombre del proyecto
TFG - Aplicación web de simulación de inversiones

## Resumen del proyecto
Este proyecto es una aplicación web que funciona como simulador de inversiones. Utiliza datos históricos reales del mercado bursátil para permitir al usuario simular decisiones de inversión a lo largo del tiempo.

Una parte importante del proyecto es el "Modo Carrera", en el que el usuario parte de una cartera inicial y avanza por turnos a través de un periodo histórico, enfrentándose a distintos acontecimientos o eventos con diferente dificultad según la configuración elegida.

## Objetivo académico y práctico
El objetivo del proyecto no es hacer trading real ni centrarse en especulación a corto plazo, sino servir como simulador y herramienta interactiva relacionada con la inversión a largo plazo, la toma de decisiones y la evolución de carteras en distintos contextos históricos.
